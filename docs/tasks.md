# PrognosOps 实施任务列表

> 版本:V1.0 | 日期:2026-10-22
> 上位文档:PROJECT_RULES.md、docs/requirements.md、docs/design.md
> 执行规则:每次只执行一个任务;每个任务完成后运行测试并汇报;等待用户指令再进入下一任务。

## 任务概览

- 总任务数:13
- 任务分类:后端开发 7 项、前端开发 1 项、测试 1 项、部署 1 项、基础设施 3 项
- 里程碑映射:M1(任务 1~3)、M2(任务 4~6)、M3(任务 7~8)、M4(任务 9~10)、M5(任务 11~13)

## 基础设施任务

- [ ] 1. 项目初始化与目录结构搭建
  - 创建后端目录结构:app/(main.py、api/、core/)、data/(演示数据)、frontend/、tests/;
  - 创建 requirements.txt(fastapi、uvicorn、numpy、scipy、httpx、python-multipart、pytest);
  - 创建 app/main.py 最小可运行实例(健康检查端点 /api/health);
  - 创建 .env.example(仅含变量名,不含真实 Key);
  - 所有文件注释使用中文。
  - 交付物:可运行的最小后端骨架,uvicorn 启动后 /api/health 返回 200。
  - _Requirements: NFR-03, NFR-05_

- [ ] 2. 内置演示数据准备与数据加载模块
  - 实现 app/core/data_loader.py:CSV 解析(自动检测空格/逗号分隔与表头)、FD001 格式校验(26 列)、错误码 E1001/E1002;
  - 准备 data/demo_train.csv(FD001 训练集子集,≥20 台设备完整生命周期);
  - 实现演示数据加载函数,构建参考集(特征 + 真实 RUL 对);
  - 交付物:模块 + 演示数据文件,单元测试覆盖格式校验与加载。
  - _Requirements: FR-01, FR-02_

- [ ] 3. 数据质量检查模块
  - 实现 app/core/quality.py:缺失值、常量传感器、周期数不足、非数值、重复行检查;
  - 输出结构化质量报告 JSON(含各检查项结果与级别);
  - 严重质量问题返回 E1003(警告但允许继续);
  - 交付物:模块 + 单元测试(构造含各类质量问题的测试数据)。
  - _Requirements: FR-03_

## 后端开发任务

- [ ] 4. 特征工程模块(420 维)
  - 实现 app/core/features.py:14 传感器选取、最近 30 周期截取、不足 30 周期前向填充(假设 A1)、展平为 420 维、z-score 标准化(假设 A2)、维度校验(E3002);
  - 标准化参数由参考集预计算并提供复用接口;
  - 交付物:模块 + 单元测试(维度校验、填充逻辑、标准化正确性)。
  - _Requirements: FR-04_

- [ ] 5. RUL 估计模块(kNN + Weibull + 离散化)
  - 实现 app/core/rul.py:参考集 kNN 检索(k=50,假设 A4)、Weibull MLE 拟合(假设 A3/A5,失败抛 E3001)、离散概率生成(H=150,假设 A6);
  - 返回 lambda、k、log_likelihood、151 维概率向量与 CDF;
  - 交付物:模块 + 单元测试(拟合收敛、参数正性、概率和为 1、CDF 单调)。
  - _Requirements: FR-05, FR-06_

- [ ] 6. 决策策略模块(四种策略)
  - 实现 app/core/decision.py:单次更换期望成本公式、IEO-C、ETO-C(假设 A7)、质量目标与 w_f(假设 A8)、IEO-Q、ETO-Q(假设 A9);
  - 在 Z={0,5,…,125} 中选最优窗口,返回各策略最优窗口、目标值、完整曲线;
  - 参数校验(cp/cc/cm/cd/alpha 范围,违规返回 E2001);
  - 交付物:模块 + 单元测试(合成分布下手算验证、z=0 特例、参数敏感性)。
  - _Requirements: FR-07, FR-08, FR-09_

- [ ] 7. 离线回测与 regret 模块
  - 实现 app/core/backtest.py:多时点决策模拟、真实成本计算、完美信息最优成本、regret 计算;
  - 无真实 RUL 标签时 regret 恒为 null(强制规则,假设 A10);
  - 返回各策略 regret 均值、中位数、完整列表;
  - 交付物:模块 + 单元测试(有标签 regret≥0、完美信息 regret=0、无标签为 null)。
  - _Requirements: FR-10, NFR-04_

- [ ] 8. 会话管理与 API 路由实现
  - 实现 app/core/session.py:内存会话创建、查询、过期清理;
  - 实现 app/api/routes.py:全部 9 个端点(见设计文档 3.1 节),统一错误响应结构;
  - FastAPI 挂载 frontend 为静态目录;
  - 交付物:完整 API 层 + 集成测试(TestClient 全链路:上传→分析→导出)。
  - _Requirements: FR-01~10, NFR-01, NFR-07_

- [ ] 9. 大模型网关模块
  - 实现 app/core/llm_gateway.py:意图解析(输出结构化 JSON,校验失败 E4002)、解释生成(基于后端结果上下文)、降级策略(无 Key/超时降级为正则与模板,标注 degraded);
  - API Key 仅从环境变量读取(规则 9);
  - 大模型不得计算任何数值(规则 8),参数变更经后端校验后生效;
  - 交付物:模块 + 单元测试(意图解析、降级路径、数值隔离校验)。
  - _Requirements: FR-11, FR-13, NFR-02, NFR-03_

- [ ] 10. 导出模块
  - 实现 app/core/exporter.py:JSON 导出(完整结果)、CSV 导出(策略对比表 + RUL 概率表)、文本报告(含自然语言解释);
  - 导出数值与 API 返回值完全一致,由后端生成;
  - 交付物:模块 + 单元测试(三种格式内容正确性)。
  - _Requirements: FR-12_

## 前端开发任务

- [ ] 11. 前端页面实现

  - 演示模式:后端不可达时显示横幅与空状态,不展示任何伪造数值(规则 7/8);

  - 交付物:完整前端,浏览器预览正常,连接后端后全功能可用。
  - _Requirements: FR-01~14_

## 测试任务

## 部署任务

- [ ] 13. Docker 部署配置与云部署
  - 编写 Dockerfile(python:3.10-slim、单端口 8080、静态前端挂载);
  - 编写 .dockerignore(排除测试、密钥、缓存);

  - _Requirements: FR-14, NFR-03_

## 执行约定

1. 每个任务开始前,先陈述实现计划;
2. 每个任务完成后,运行相关测试并汇报变更文件;
3. 任何任务不得引入超出设计文档的功能;
4. 工程假设(A1~A10)在代码注释中标注对应编号;
5. 等待用户明确指令后方可开始下一任务(规则 12)。
